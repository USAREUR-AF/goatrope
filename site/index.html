Tie distant machines to one link, or tap the link they share.

goatrope turns one small computer with two Ethernet ports into a tap or a relay. Joining distant sites is being designed, and is not in 0.1.0. One file declares what it does. It runs with nothing else of ours installed.

Three roles on one link

Each role is off unless the file declares it.

Tap

Records the link to a bounded ring of capture files, inline or from a copy.

Built. Tested in network namespaces on Ubuntu 24.04 and 26.04.

Decode and send

Takes the tap's copy, keeps the datagrams you name, and delivers them. It never sends on the tapped link.

Built. Tested the same way.

Relay

Lets one remote machine exchange named datagrams with named machines on the link.

Work in progress. Runs only while someone runs it.

What happens when the machine goes dark

A computer that bridges two ports is in the link, and no software changes that. The declaration has to say which mode you chose. There is no default.

Listen fails open

A tap device or a switch mirror port hands goatrope a copy. It receives and does not send.

The link carries on. Only the recording has a gap.

Inline fails closed

Every frame passes through the machine's bridge.

The link is down until the machine is back. A hardware watchdog restarts a hung one.

Install in one command

Write the declaration, then run the install. It refuses, changing nothing, when a port carries your session, the default route or an address. Release 0.1.0 is one archive for arm64 and amd64.

/etc/goatrope/goatrope.toml
schema = 1 [tap]mode = "listen"source = "mirror-port"ports = ["enxPORTA"]management = "eth0" [tap.record]ports = ["enxPORTA"]filter = ""        # every framefile_mb = 50files = 40
On the machine
sudo ./bin/goatrope install --config /etc/goatrope/goatrope.toml
  1. Ubuntu Server 24.04 or 26.04, reached over a third interface. sudo apt-get install -y tcpdump ethtool
  2. Download release 0.1.0, check its signature with the cosign command in release.yml and its contents with sha256sum -c SHA256SUMS, unpack it, and change into its directory.
  3. Fill in the declaration from an example.
  4. Cable the link, then run the command above.
  5. sudo goatrope check exits 0 when the machine matches the file, and 3 when anything differs.
  6. sudo goatrope uninstall puts the ports back as it found them.

Every step: the install card.

Safety properties

  • Default deny. The relay carries only what a rule names, and refuses to run while the kernel would route around it.
  • No egress from a listen port. The drop is in place before the port goes up, and check reads it.
  • A refusal changes nothing. Tests compare the files and ports before and after each one.
  • Pinned components. A decoder or converter is hashed and copied in one read, and the copy is what runs.
  • Signed releases. Each release is the archive, its checksums and a keyless signature made by the release workflow at the tag. 0.1.0 is the first.
  • A limit. A process with CAP_NET_RAW can get past the listen drop. Where sending must be impossible, use a tap that cannot transmit. Known limits
